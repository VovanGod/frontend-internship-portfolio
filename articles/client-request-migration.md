# Перенос клиентских запросов

Я подключился к командному проекту, который уже шёл до моего появления. Моя часть — несколько клиентских сценариев в Избранном и реферальном разделе: новые вызовы, проверка пользовательского пути и уборка старого кода после переключения.

## Как проходила миграция

~~~mermaid
flowchart LR
    A["Пользовательское действие"] --> B["Веб-интерфейс"]
    B --> C{"Флаг включён?"}
    C -->|нет| D["Старый путь"]
    C -->|да| E["Новый серверный путь"]
    D --> F["Ответ в интерфейсе"]
    E --> F
~~~

1. Разбирал текущий вызов и данные, которые нужны экрану.
2. Добавлял новый путь под флагом и менял вызов на вебе. При необходимости согласовывал изменения со смежными сервисами.
3. Дожидался релизов всех затронутых частей.
4. Проходил пользовательский сценарий на стенде и в продукте с включённым флагом.
5. После успешной проверки переводил сценарий на новый путь.
6. Удалял старые вызовы, когда они больше не использовались.

Работал с действиями в Избранном, онбордингом, историей операций и несколькими вспомогательными сценариями. Здесь намеренно нет названий внутренних обработчиков, конфигураций и схем сервисов.
