# ИИ-скилл для веб-интеграционных тестов

Я описал повторяемый процесс написания интеграционных тестов в виде ИИ-скилла. Он помогает пройти путь от набора тест-кейсов до небольших задач, проверок в браузере и подготовленного PR.

## Один цикл

~~~mermaid
flowchart TD
    A["Пул тест-кейсов"] --> B["Прочитать шаги и ожидаемый результат"]
    B --> C["Сверить с существующим покрытием"]
    C --> D["Сгруппировать недостающие сценарии"]
    D --> E["Разбить работу на задачи"]
    E --> F["Пройти сценарий вручную на тестовой странице"]
    F --> G["Написать тест для нужной платформы"]
    G --> H["Локально запустить изменённый тест"]
    H --> I{"Шесть успешных прогонов подряд?"}
    I -->|нет| J["Разобрать причину и начать серию заново"]
    J --> H
    I -->|да| K["Локальные проверки и саморевью"]
    K --> L["Commit, push и PR"]
~~~

Главное правило скилла — сначала увидеть сценарий глазами пользователя. После последней правки тест проверяется локально: шесть успешных прогонов подряд, затем форматирование, просмотр diff и только после этого отправка изменений.

Скилл не привязан к одной странице или одному проекту: адрес стенда и набор проверок выбираются по текущему сценарию.
