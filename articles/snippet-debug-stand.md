# Стенд для разбора товарных карточек

Когда карточка товара выглядит не так, как ожидалось, полезно быстро увидеть две вещи: какие данные получил интерфейс и как тот же товар выглядит в других вариантах карточки. Я сделал для этого удобный путь из самой карточки на отдельный стенд.

## Что сделал

- Добавил вход в инструменты разбора прямо из карточки.
- Сделал просмотр данных, по которым карточка была собрана.
- Добавил переход к стенду с вариантами отображения того же товара.
- На стенде организовал сравнение вариантов и просмотр данных каждого из них.

Так проще отделить проблему данных от проблемы отображения: можно открыть исходный ответ, сравнить темы и проверить поведение без ручного поиска товара в служебных инструментах.

## Почему это полезно

Инструмент помогает разработчику или тестировщику быстро повторить проблему и передать коллеге конкретный пример. Не нужно восстанавливать весь путь к карточке по памяти.
